1. 全体構成

制御は「物体レベルの軌道生成」「2台のベースへの速度分配」「各グリッパーの接触力制御」 の3層で構成される。上位層は搬送物体の目標位置・姿勢を生成し、中央制御器がその目標を AMIR1とAMIR2の速度指令へ変換する。把持制御器は搬送制御とは独立した周期で、4本の指の 接触と法線力を監視し続ける。

第I部　把持制御

2. 入力・出力と制御対象

把持制御器は、各AMIRに対して左右2本、合計4本の指を監視する。1台のAMIRでは左右指が 1つの駆動関節に連動するため、左右の力を独立に指定することはできない。したがって、 左右力の平均と最大値を使って、共通のグリッパー角度を補正する。

種別信号用途
入力左右指の接触情報指と搬送物体が実際に接触しているか確認
入力左右指の6軸反力指法線方向X成分から法線力を算出
入力グリッパー関節角度現在位置、左右AMIR間の整合性を確認
出力GripperCommandグリッパー位置と最大努力を指定
出力把持状態搬送開始許可と安全監視に使用

3. 法線力の計測と前処理

3.1 法線力

指センサー座標系のX軸を接触面法線とし、次式で正の法線力へ変換する。

Fn[k] = |Fx[k]|

この値は指先ロードセルの純粋な接触力ではなく、関節を通過する反力である。そのため、 搬送加速度、物体慣性、摩擦方向の荷重、複数接触点の切替も含まれる。

3.2 指数移動平均

接触ソルバによる高周波変動を抑えるため、生値に指数移動平均を適用する。

F̄n[k] = α Fn[k] + (1 − α) F̄n[k−1]
α = 0.25

通常の目標力制御は平滑値を用いる。一方、過大力判定では検出が遅れないよう、 max(生値, 平滑値) を使用する。

3.3 把持直後のバイアス

HOLDINGへ入る直前の0.5秒間の6軸反力平均をバイアスとして保存する。 補正反力は計測・Excel表示用であり、把持制御そのものは生法線力と平滑法線力を使用する。

Wcal(t) = Wraw(t) − mean(Wraw)把持直後0.5 s

4. 把持の状態遷移

状態処理次状態への条件

5. 接触探索と目標力制御

5.1 接触前

両指接触が成立するまでは、1制御周期ごとにグリッパーを閉方向へ進める。 最初の接触前は0.002 rad、いったん接触を検出した後の再探索は0.0002 radとする。 再探索を細かくすることで、接触のON/OFF付近における大きな反力ジャンプを抑える。

qcmd[k+1] = clamp(q[k] + Δqsearch, qopen, qclose)

5.2 両指接触後

左右指の平均法線力を目標14 N/指へ近づける位置補正型P制御を行う。

eF = Ftarget − (F̄L + F̄R)/2
Δq = clamp(KF eF, −Δqmax, +Δqmax)
qcmd[k+1] = clamp(qbase + Δq, qopen, qclose)

力誤差が許容帯内なら位置を保持する。どちらか一方の力が 目標値 + 許容差を超えた場合は、平均値ではなく大きい側を基準に開方向へ補正し、 片側だけの過圧縮を防ぐ。

5.3 把持成立条件

現在の回転搬送では、次の条件をすべて満たして初めて把持成立とする。

  • AMIR1とAMIR2の左右指、合計4指で物体接触が確認される。
  • 4指の平滑法線力が目標14 Nの許容帯に入る。
  • グリッパー角度が許容範囲内で、2台間の角度差が0.05 rad以下である。
  • 上記状態が0.30秒連続する。

6. 支持台撤去と搬送開始インターロック

物体は把持成立前に落下しないよう、一時支持台上に生成される。支持台は次のAND条件が 成立してから1.0秒待ち、Gazeboのモデル削除サービスで撤去される。

AMIR1把持 = true
AND AMIR2把持 = true
AND 把持制御状態 = HOLDING
AND 物理接触 = CONTACT_OK

搬送制御器側も、両把持状態、支持台撤去、コントローラ稼働、姿勢情報の鮮度を確認する。 したがって、支持台が先に消えることや、把持未成立のままベースが動き出すことを防ぐ。

さらに搬送開始前の2.0秒間について、各指が8 N以上、各指の変動幅が2 N以下、4指の 最新値平均が14 ±5 N以内、センサー更新停止が0.25秒未満であることを確認する。

7. 搬送中の把持維持

HOLDINGに入ると、把持成立時の関節位置を保持位置として記録する。 現在は prioritize_grasp_retention=true であり、搬送中の短い反力ピークを理由に 指を開かない。これは、開動作によって接触が失われ、物体が落下する問題への対策である。

7.1 弱い指の回復

左右どちらかが最低保持力8 N未満になった場合だけ、閉方向へ回復する。

Δq = clamp(KF(Ftarget − min(FL,FR)), 0, Δqmax)

7.2 20 N上限の意味

重要：現在の20 Nは「超過検出し、警告する基準」であり、搬送中の力を必ず20 N以下に 飽和させる保証値ではない。把持維持優先モードでは、20 Nを超えても短時間のピークなら 指を開かず、成立位置を保持する。したがってExcelに20 N超過が記録される場合がある。 厳密な20 N制約と落下防止を同時に保証するには、各指独立駆動、力センサーの分離、または 搬送加速度のさらなる制限が必要になる。

物理接触と最低力条件が2.0秒以上失われた場合は把持喪失エラーとなり、把持状態をfalseにする。 協調搬送制御器は把持状態falseを受けると両ベースを停止する。

第II部　搬送制御

8. 座標系と物体姿勢

座標系定義
worldGazebo世界固定座標系
cooperative_transport_frame物体重心を原点とし、物体と一体で回転する搬送座標系
物体 +X長手方向。最初の直進は初期姿勢の+X方向
物体 +Y幅方向
world +Y回転後の2回目の直進方向

物体姿勢はGazeboのモデル姿勢から取得し、 /cooperative_transport/measured_payload_poseとして配信する。回転制御器はこの実測姿勢を 優先し、取得できない場合のみ2台のベース中央から物体姿勢を推定する。

8.1 物体とTCPの相対関係

搬送区間の開始時に、物体から各グリッパーTCPへの相対変換を保存する。

TOGᵢ = (TWO)⁻¹ TWGᵢ
TWGᵢ,target = TWO,target TOGᵢ

これにより物体目標を1つ生成すれば、両TCPの目標が一意に得られる。直進終了時と回転終了時に 相対変換を再取得するため、前区間で生じた微小な接触ずれを次区間へ累積させにくい。

9. 搬送シーケンス

WAITING→ GRASP_CHECK→ INITIALIZE→ TRANSLATING→ 直進整定→ ROTATING→ 回転整定→ Y直進→ FINISHED
  1. 開始前：把持、支持台撤去、4指力の安定、姿勢・TF・コントローラを確認する。
  2. 第1直進：物体初期座標系+X方向へ既定距離（標準1 m）移動する。
  3. その場回転：物体重心を通るworld-Z軸周りに指定角度（例：90°）回転する。
  4. 第2直進：回転終了位置からworld +Y方向へ既定距離（標準1 m）移動する。
  5. 整定：各区間の終端で目標を保持し、誤差が一定時間許容範囲内に入ったことを確認する。

10. 加速度制限軌道

直進距離と回転角はいずれも同じ台形速度プロファイルで生成する。距離が短く最高速度へ 到達できない場合は三角速度プロファイルとなる。急な速度変化を避け、接触力の衝撃を抑える。

加速区間：s(t) = 0.5 a t²
等速区間：s(t) = sramp + vmax(t − tramp)
減速区間：s(t) = starget − 0.5 a (T − t)²

標準値は直進速度0.05 m/s、直進加速度0.025 m/s²、回転速度1°/s、回転加速度0.25°/s²である。 制御周期は0.01秒で、軌道時間はGazeboのROS時間を使う。

11. 2台の剛体協調運動学

11.1 隊形から求める物体姿勢

AMIR1、AMIR2の平面位置をp₁、p₂とすると、隊形中心とヨー角を次で推定する。

pc = (p₁ + p₂)/2
ψc = atan2(y₂ − y₁, x₂ − x₁)

現在の設定では並進位置フィードバックに実測物体位置を使用し、ヨー角制御には隊形角を使用する。 これは、対向する摩擦把持による実測物体ヨーの符号・遅れがベース制御を不安定化するのを避けるためである。

11.2 物体中心のP制御

vc = Kp(pgoal − pfeedback)
ω = clamp(Kψ wrap(ψgoal − ψformation), ωmax)

中心速度は最大線速度で飽和し、回転角誤差は−π～πへ正規化する。

11.3 各AMIRへの速度分配

隊形中心から各AMIRまでのベクトルをrᵢとすると、剛体運動の速度は次式になる。

vᵢ = vc + ω × rᵢ
vᵢx = vcx − ω rᵢy
vᵢy = vcy + ω rᵢx

世界座標速度を各AMIRのローカル座標へ回転変換し、メカナムベースへ linear.x、linear.yとして出力する。AMIR2は物体を挟んで反対向きなので、 目標機首角にπを加える。各AMIRの角速度には機首角補正も加える。

ωᵢ = ωfeedback + Kheading wrap(ψdesired,i − ψᵢ)

11.4 指令の加速度制限

算出した速度指令は、前周期の指令から許容加速度以内で変化させる。線速度はベクトルの向きを 保ったまま増分を制限し、角速度も同様に制限する。これにより直進開始時の把持力衝撃を抑える。

12. 距離一定制御

搬送開始時の2台間距離d*を保存し、搬送中の距離dとの差を閉ループ補正する。 2台へ等量・逆方向の速度を加えるため、理想的には物体中心を移動させず、開き過ぎ・押し込み過ぎだけを補正する。

ed = d − d*
vd = clamp(0.5 Kd ed, vd,max)
v₁ ← v₁ + vd n,　v₂ ← v₂ − vd n

nはAMIR1からAMIR2へ向かう単位ベクトルである。現在値は Kd=0.8、補正速度上限0.012 m/s、距離許容差0.005 mである。

13. 追従遅れ対策

13.1 参照進行ガバナ

物体が指令へ追従できないまま目標だけが先へ進むと、指に引張り・ねじり荷重が集中する。 そこで追従誤差が上限へ達すると軌道時間の進行を一時停止し、物体が追いついてから再開する。

対象停止しきい値再開しきい値
直進位置誤差0.04 m0.02 m
回転姿勢誤差2°1°

停止値と再開値を分けたヒステリシスにより、しきい値付近の高速な停止・再開切替を防ぐ。

13.2 回転終端の補正

摩擦把持にはねじりのコンプライアンスがあるため、隊形が90°へ到達しても物体がわずかに遅れる。 整定中だけ、物体角度誤差に比例した有限のオーバードライブを搬送目標へ加える。

θtransport = θtarget + clamp(Ks(θtarget − θactual), ±4°)
Ks = 2.0

完了判定は補正後の隊形目標ではなく、本来の物体目標に対して行う。このため補正量だけ回り過ぎて 完了と判定されることはない。

14. 完了判定と安全停止

14.1 区間完了

  • 直進：物体位置誤差が0.02 m以内で1.0秒継続。
  • 回転：位置誤差0.02 m以内かつ姿勢誤差1°以内で2.0秒継続。
  • Y直進：物体位置誤差が0.02 m以内で1.0秒継続。

許容範囲から外れた場合は継続時間をリセットする。整定タイムアウト時はエラー停止する。

14.2 直ちに停止する条件

  • いずれかのAMIRの把持状態がfalse。
  • オドメトリまたは物体姿勢がタイムアウト。
  • 位置追従誤差が0.10 m、または姿勢追従誤差が15°を超過。
  • 2台間距離が2.30～3.10 mの範囲外。
  • ベース速度、関節範囲、物体すべりの監視条件に違反。
  • 非常停止がラッチされている。

安全監視は片方だけでなく両ベースを同時に停止する。ラッチ後は原因が解消され、明示的に リセットされるまで再開しない。

14.3 アドミッタンス制御

内力を逃がす1軸アドミッタンス Mẍ + Dẋ + Kx = Fも実装されているが、通常の回転搬送では無効である。 有効化した場合のみAMIR2のローカルY速度へ最大0.004 m/sの補正を加える。

16. 実装上の限界と調整時の注意

  1. 1台の左右指は独立制御できない。片側の力だけが高い場合、共通関節を開く以外に直接的な均等化手段がない。
  2. 指反力は純粋な法線力ではない。搬送加減速による動的反力も含むため、20 N超過が直ちに静的な締付け過大を意味するとは限らない。
  3. 把持維持と厳密な力上限は競合する。現在は落下防止を優先するため、搬送中ピークに対する開動作を抑制している。
  4. 剛体隊形モデルは接触の弾性・すべりを直接表さない。それらは実測物体姿勢、追従停止、距離制御、安全監視によって外側から補う。
  5. 実機化にはセンサー再定義が必要。Gazeboモデル姿勢の代わりに外部計測または物体姿勢推定を使用し、指法線力の軸・符号・バイアスを再校正する必要がある。
把持力変動をさらに減らす場合は、目標力だけを上げるより、直進加速度、2台間距離補正速度、 指接触剛性、左右独立力計測の順に原因を切り分ける方が安全である。
