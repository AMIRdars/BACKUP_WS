## 復元後のビルド

ROS 2 Humble と必要な依存パッケージを導入した環境で実行してください。ビルド後、上記コマンド集から必要なシミュレーションを起動できます。

```bash
cd /home/dars5070/ros2_humble_ws
source /opt/ros/humble/setup.bash
colcon build --symlink-install --packages-up-to cooperative_transport_bringup
source install/setup.bash
```

このバックアップではシミュレーションの再実行・動作検証は行っていません。保存元とバックアップのファイル一致を確認しています。
