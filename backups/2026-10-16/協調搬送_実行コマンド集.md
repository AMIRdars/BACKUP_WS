# 協調搬送 実行コマンド集

ROS 2 Humble の協調搬送シミュレーションを実行するためのコマンド集です。各コマンドは、別途指定がない限り新しい端末で実行してください。

## 統合シミュレーションの動作を個別に確認する

初回と launch ファイル変更後は、ワークスペースで `colcon build --symlink-install --packages-select cooperative_transport_bringup` を実行してください。各コマンドは別々に起動し、前のシミュレーションを `Ctrl+C` で終了してから次を起動します。

```bash
cd /home/dars5070/ros2_humble_ws
source /opt/ros/humble/setup.bash
source install/setup.bash
```

### 直進のみ（搬送物の初期姿勢の前方へ 1.0 m）

```bash
ros2 launch cooperative_transport_bringup integrated_transport_simulation.launch.py \
  headless:=false forward_distance_m:=1.0 rotation_angle_deg:=0.0 \
  right_distance_m:=0.0 enable_pivot:=false record_data:=true
```

### 並進のみ（搬送物の右方向へ 1.0 m）

```bash
ros2 launch cooperative_transport_bringup integrated_transport_simulation.launch.py \
  headless:=false forward_distance_m:=0.0 rotation_angle_deg:=0.0 \
  right_distance_m:=1.0 enable_pivot:=false record_data:=true
```

### 回転のみ（搬送物の重心まわりに 90 度）

```bash
ros2 launch cooperative_transport_bringup integrated_transport_simulation.launch.py \
  headless:=false forward_distance_m:=0.0 rotation_angle_deg:=90.0 \
  right_distance_m:=0.0 enable_pivot:=false record_data:=true
```

いずれも把持後に指定した動作だけを実行します。元の統合コマンドでは最後に支点回転も行うため、個別確認では `enable_pivot:=false` を指定します。距離と角度は各引数の値を変更して調整できます。

`record_data:=true` で4本の指先の力センサー値と搬送状態を10 Hzで記録し、動作完了時に `~/ros2_humble_ws/rotation_measurements/rotation_<角度>deg_<日時>.xlsx` へ保存します。保存先は `excel_output_directory:=<ディレクトリ>`、周期は `recording_rate:=<Hz>` で変更できます。直進と並進のファイル名にはどちらも `rotation_0deg` が入るため、実行日時で区別してください。

### 指定点回転のみ（AMIR1を支点に90度）

```bash
ros2 launch cooperative_transport_bringup pivot_rotation_simulation.launch.py \
  headless:=false target_angle_deg:=90.0 \
  angular_velocity_deg_s:=1.0 angular_acceleration_deg_s2:=0.25 \
  record_data:=true
```

AMIR1の初期位置を支点として、AMIR2が円弧を描くように回転します。指先4本の力と指定点回転角度を10 Hzで記録し、完了時に `~/ros2_humble_ws/rotation_measurements/pivot_90deg_<日時>.xlsx` へ保存します。回転角度は `target_angle_deg` で変更できます。

## 統合

```bash
cd /home/dars5070/ros2_humble_ws
source /opt/ros/humble/setup.bash
source install/setup.bash
```

```bash
ros2 launch cooperative_transport_bringup integrated_transport_simulation.launch.py \
  headless:=false forward_distance_m:=1.0 rotation_angle_deg:=90.0 \
  right_distance_m:=0.0 world_y_distance_m:=1.0 enable_pivot:=false \
  record_data:=true \
  translation_velocity_m_s:=0.10 translation_acceleration_m_s2:=0.025 \
  angular_velocity_deg_s:=1.0 angular_acceleration_deg_s2:=0.25
```
